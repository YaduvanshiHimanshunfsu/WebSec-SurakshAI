error Critical Vuln-ID: SEC-2023-0891

Missing Content-Security-Policy Header

The application is missing a Content-Security-Policy (CSP) HTTP response header. CSP is a widely supported security standard that helps prevent Cross-Site Scripting (XSS), clickjacking, and other code injection attacks.

visibility What it means

Without a CSP, the browser trusts all content received from the server. An attacker who successfully injects malicious scripts into your application can execute them in the victim's browser, potentially stealing session tokens or sensitive user data.

healing How to fix it

Configure your web server to return the Content-Security-Policy HTTP header with values restricting resources to trusted domains. Start with a reporting-only policy to monitor potential breakages before enforcing.
